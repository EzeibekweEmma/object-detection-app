# YOLO26s model

`yolo26s_w8a32.tflite` is the official Ultralytics YOLO26s COCO model from the
[`v0.6.6` yolo-flutter-app release](https://github.com/ultralytics/yolo-flutter-app/releases/tag/v0.6.6).

- SHA-256: `7a598838082251ef8e1d3b8f06f356ad532f8fe3a24c7eeeed68b52d28525036`
- Input: FP32 RGB, 640 × 640
- Output: raw one-to-many COCO detections
- Quantization: w8a32 (INT8 weights, FP32 activations)
- Model license: [Ultralytics AGPL-3.0](https://www.ultralytics.com/license)

The application source remains MIT-licensed. Confirm that the model's AGPL-3.0
terms fit your deployment, or replace it with an appropriately licensed custom
YOLO26s export.
